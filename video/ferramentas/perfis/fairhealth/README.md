# Perfil fairhealth

O gosto dos reels da fairhealth (@fairhealth.br), separado do fluxo. As skills `edit-*` leem daqui.
Criado em 09/11/2026 a partir de três referências escolhidas pela Nina e das regras da marca.

| Arquivo | O que decide |
|---|---|
| `identidade.md` | cores, fontes, logo, áreas seguras, o que nunca usar |
| `estilo-motion.md` | legendas, números, pílulas, cartões, velocidades e curvas |
| `estilo-camera.md` | zoom, punch, aproximação lenta |
| `estilo-cortes.md` | como a Marília grava e o que o corte faz |
| `estilo-som.md` | efeitos sonoros e música |
| `catalogo.md` | padrões que já funcionaram (cresce a cada vídeo aprovado) |
| `analises/sintese.md` | o que foi visto em cada referência |

Fonte da marca, em caso de dúvida: `instagram/diretrizes-criativas.md` e `instagram/voice.md`. Onde este
perfil discordar delas, valem elas.

Tudo aqui é tendência, não regra, exceto o que vem da marca (cores, logo, número com fonte), que é firme.
