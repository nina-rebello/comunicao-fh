# Ilustrações

Ilustrações em traço criadas pela Nina (19/10) para o post de 21/10 ("Por que a fairhealth existe?").

**Como foram preparadas:**
- A cor do traço passou para o verde da marca (#1F3A36).
- O fundo de fora ficou transparente.
- O interior das formas fechadas ficou creme (#F0F0E9), para a ilustração aparecer sobre o Tiffany.

O processo está registrado em `ilu_proc.py`, que fica no rascunho da sessão e não no repositório.

| Arquivo | O que mostra |
| --- | --- |
| hospital.png | Hospital, com o consultório por dentro e uma médica apresentando |
| escritorio.png | Escritório do Cuidado: uma sala de atendimento dentro do escritório, com uma médica apresentando |
| hospital-linhas.png, escritorio-linhas.png | As mesmas ilustrações, só com o traço (sem o creme), para fundos claros |
