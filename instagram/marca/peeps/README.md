# Pessoas ilustradas (Open Peeps)

Ilustrações de pessoas em traço, usadas no post de 21/10 (arte v3), para humanizar os slides.

- **Origem:** [Open Peeps](https://www.openpeeps.com/), de Pablo Stanley. Licença CC0 (domínio público): uso
  comercial livre, sem atribuição obrigatória.
- **Como foram feitas:** cada pessoa junta uma pose, um cabelo e um rosto do pacote `react-peeps` (licença MIT).
  As peças foram convertidas para SVG com o traço no verde da marca (#1F3A36) e o preenchimento branco.
- **Regra:** são ilustrações. Nunca apresentar como alguém do time, cliente ou colaborador atendido.
